# Spark Lang

Скриптовый язык с питон-like синтаксисом, компилируется в нативный Rust —
аналог AutoHotkey, только кроссплатформенный (Linux/Wayland, macOS, Windows)
и на русском. Один скрипт — один бинарник, без рантаймов и зависимостей.

```spark
имя = arg(1)
if имя == "":
    say("укажи имя окна")
else:
    say(window_focus(имя))
```

## Запуск

```bash
spark скрипт.sk -o app        # скомпилировать
spark скрипт.sk --run         # скомпилировать во временный файл и запустить
spark скрипт.sk --release     # opt-level=3 (по умолчанию 1)
```

## Автоматизация ОС (v0.3) — как AutoHotkey

| Spark | Русский синоним | Что делает |
|---|---|---|
| `send_hotkey("CTRL+SHIFT+T")` | `сочетание("…")` | нажать сочетание клавиш в активное окно |
| `type_text("текст")` | `напечатать("…")` | напечатать текст (на Wayland юникод нативно) |
| `mouse_click(x, y)` / `mouse_right_click(x, y)` | `клик(x, y)` | клик по координатам |
| `mouse_move(x, y)` / `mouse_scroll("down", 3)` | `движение_мыши` / `прокрутка` | курсор и прокрутка |
| `window_list()` | `окна()` | список открытых окон «класс — заголовок» |
| `window_focus("firefox")` | `фокус("…")` | фокус на окно по классу или заголовку |
| `window_close("firefox")` | `закрыть_окно("…")` | закрыть окно |
| `window_minimize("zed")` / `window_maximize("zed")` | `свернуть_окно` / `развернуть_окно` | размер окна |
| `window_move_desktop("zed", 3)` | `перенести_окно("…", 3)` | перенести окно на стол |
| `desktop_switch(3)` / `desktop_next()` / `desktop_prev()` | `стол(3)` / `следующий_стол()` / `предыдущий_стол()` | рабочие столы |
| `volume_set(50)` / `volume_get()` / `volume_mute()` | `громкость` / `без_звука` | звук |
| `brightness_set(70)` | `яркость(70)` | яркость экрана |
| `screenshot("/tmp/shot.png")` | `скриншот("…")` | снимок экрана в файл |
| `clip_set("текст")` / `clip_get()` | `в_буфер("…")` / `буфер()` | буфер обмена |
| `http_get("https://…")` | `запрос("…")` | HTTP GET, тело ответа |
| `app_open("firefox")` / `app_quit("firefox")` | `открыть_приложение` / `закрыть_приложение` | запуск и закрытие приложений |
| `battery()` | `батарея()` | заряд в процентах |
| `screen_size()` | `экран_размер()` | «1920x1080» |
| `sleep_ms(500)` | `пауза(500)` | пауза в миллисекундах |

Платформы:

- **Linux** — всё; окна и столы через Hyprland (Wayland), ввод через wtype
  (юникод нативно) с честным падением на xdotool (X11), мышь через ydotool,
  звук через pactl, яркость через brightnessctl, скриншот через grim,
  буфер через wl-copy/wl-paste
- **macOS** — клавиатура/текст через osascript, мышь через cliclick,
  звук/буфер/скриншот/приложения/батарея/экран; окна и столы пока Linux
- **Windows** — клавиатура через SendKeys, буфер через PowerShell,
  приложения/батарея/экран; окна, столы, звук и яркость — клавишами

Инструменты, которых нет на платформе, отвечают честным текстом
(«поддержано пока на Linux»), а не молча делают ничего.

## Системные built-ins

| Spark | Что делает |
|---|---|
| `arg(1)` | аргумент командной строки №1 |
| `env("HOME")` | переменная окружения |
| `run("uptime -p")` | shell-команда, stdout (с таймаутом, без зависаний) |
| `launch("gtk-launch …")` | команда без ожидания — для запуска приложений |
| `read_file("путь")` / `write_file("путь", "текст")` | файлы |
| `notify("заголовок", "текст")` | системное уведомление |
| `say("фраза")` | фраза на stdout — Джарвис озвучит её голосом |
| `input()` | строка со stdin |
| `str(x)` / `int(x)` | приведение типов |

## Строковые методы (питоновские)

`s.upper()` / `s.lower()` / `s.trim()` / `s.replace("a", "b")` /
`s.contains("x")` / `s.startswith("x")` / `s.endswith("x")` / `s.len()` /
`s.split(",")` (даёт список) / `",".join(список)` / `s.find("x")`.

## Язык

- Питон-синтаксис: `def`, `if/elif/else`, `for x in …`, `while`, классы,
  `print()`, `import` других `.sk`-модулей
- Юникод-идентификаторы: переменные и функции на русском (`действие = arg(1)`)
- Комментарии `#`
- Строки склеиваются `+`, сравнения и арифметика как в Python
- Сборка: rustc `--edition 2021`, только std — бинарник ни от чего не зависит

## Как библиотека

```rust
let ast = spark::parse_source(source)?;
let rust_code = spark::codegen::compile_to_string(ast);
// rust_code — валидный Rust: прелюдия автоматизации внутри
```

Так Джарвис компилирует голосовые плагины-автоматизации: `.sk` → AST →
Rust → нативный бинарник с кэшем по хэшу исходника.
